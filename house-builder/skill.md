# 房屋建造预设

## 插件检查

本预设使用Minecraft原生fill和setblock命令，无需任何插件。

## 使用方法

1. 所有以下操作均由你完成而不是玩家
2. **先问风格**：玩家说"造个房子"时，先询问想要什么风格，不要直接开建。提供以下选项：
   - 🏡 **田园风格** - 温暖自然，斜顶带屋檐，有花园
   - 🏢 **现代风格** - 简洁明亮，大落地窗，平顶悬挑
   - 🏰 **中世纪风格** - 厚重石材，高斜顶+城垛，带塔楼
   - 🏯 **日式风格** - 大挑檐屋顶，回廊，枯山水庭院
   - 🔄 **让AI自由发挥** - 根据环境自动选择最合适的风格
3. 通过 `/data get entity <玩家名> Pos` 获取玩家的坐标
4. **样式参考**：选定风格后，参照同目录下的对应文件获取详细方案：
   - `rustic.md` - 田园风格
   - `modern.md` - 现代风格
   - `medieval.md` - 中世纪风格
   - `japanese.md` - 日式风格
5. （重要）命令一定要分开执行，上一条执行完拿到结果再执行下一条，一次输出最多只能包含一次工具调用
6. （重要）除非用户说明，请勿使用相对坐标（~）
7. 必须调用TODO，持续跟踪进度

## 核心原则（避免火柴盒）

要让房子好看，必须做到以下几点：

| # | 原则 | 说明 |
|---|------|------|
| 1 | **长宽不等** | 不要正方形，推荐比例 3:2 或 5:3 |
| 2 | **高度够** | 至少 5-6 格高（含屋顶），3-4 格室内净高 |
| 3 | **立面有层次** | 墙面不能纯平，用柱子、窗框、腰线做立体感 |
| 4 | **屋顶有细节** | 挑出屋檐、不同材质、装饰性屋脊 |
| 5 | **门窗有框** | 门窗周围用不同材质围一圈，不要直接挖洞 |
| 6 | **环境搭配** | 种树、铺路、照明、栅栏，让房子融入环境 |

## 选择尺寸

**不要使用 7x7 这类正方形！** 根据风格选择推荐尺寸：

| 风格 | 推荐占地 | 高度 | 说明 |
|------|----------|------|------|
| 田园风 | 9x7 / 11x9 | 6-7 格 | 长宽不等，横向舒展 |
| 现代风 | L形 9x7+5x5 | 5-6 格 | 非对称布局，体块交错 |
| 中世纪风 | 9x11 | 9-10 格 | 窄而高，强调垂直感 |
| 日式风 | 9x11（+挑檐） | 5-6 格 | 横向舒展，屋檐深远 |

尺寸不是死的，可以根据玩家需求调整，但 **保持比例** 而非正方形。

## 通用建造流程

以下是所有风格通用的建造顺序，具体方块和命令参考对应风格文件：

| 步骤 | 内容 | 说明 |
|------|------|------|
| 1 | 获取坐标 | `/data get entity <玩家名> Pos` |
| 2 | 平整场地 | 根据房屋占地清除树木和地形 |
| 3 | 地基 | 按风格文件中的材料铺设地板 |
| 4 | 骨架/立柱 | 四角和关键节点的承重柱 |
| 5 | 墙壁 | 填充墙体，留出门窗位置 |
| 6 | 门窗洞 | 按风格文件中的尺寸留空 |
| 7 | 安装门窗 | 门、玻璃板、窗框 |
| 8 | 屋顶 | 按风格建造对应屋顶（关键步骤） |
| 9 | 外部装饰 | 墙面细节、照明、台阶 |
| 10 | 内部装修 | 家具、照明、地毯 |
| 11 | 环境美化 | 路、树、花园、栅栏 |

## 注意事项

- 必须先通过 `/data get entity <玩家名> Pos` 获取玩家的坐标
- **必须先问玩家想要什么风格**，除非玩家已经明确说了风格。不要默认用某种风格
- 选定风格后，参考对应 `.md` 文件中的详细方案来建造
- /fill命令执行后如果返回"没有方块被填充"，则代表此处已经有正确的方块了
- 合理利用/fill 的 replace 模式是可以事半功倍的
- 需要删除方块时用 `/fill ... air replace`
- 除非用户明确说明，使用绝对坐标而不是相对坐标
- (重要)注意门分为上下两部分，应分开放置
- (重要)注意床分为两部分，放在一起时应注意朝向
- (重要)注意坐标与空间位置的关系，不要搞错了
- 必须包含房屋的所有部分（内外装饰都要做全）
- 建造完成后检查是否像"火柴盒"（正方形/平墙/无细节），是就想办法加装饰补救
- 为避免被打断，开始前执行 `/cli exempt_anti_loop` 来关闭防循环检测

## 指令语法

### /fill指令
```
/fill <from> <to> <block> replace [<filter>]
/fill <from> <to> <block> [destroy|hollow|keep|outline|replace]
```

| 模式 | 效果 | 适用场景 |
|------|------|----------|
| destroy | 破坏原有方块（掉落物品）后填充新方块 | 清理区域并获取资源 |
| hollow | 仅填充区域外层，内部填充为空气 | 快速建造空心立方体 |
| keep | 仅替换空气方块，保留原有非空气方块 | 保护现有结构 |
| outline | 仅填充区域外层，内部保持不变 | 为区域添加边框 |
| replace | 默认模式，替换所有方块（无参数时）；加时仅替换指定方块 | 批量替换特定方块 |

### /setblock指令
```
/setblock <x> <y> <z> <block> [replace|destroy|keep]
```

| 模式 | 作用 | 特点 |
|------|------|------|
| replace | 直接替换目标方块 | 不掉落物品，默认模式 |
| destroy | 先破坏原方块再放置 | 会掉落方块物品，相当于手动挖掉再放 |
| keep | 仅在空气位置放置 | 非空气方块不会被改变 |


根据玩家要求调整风格文件中的尺寸参数，保持比例放大。
