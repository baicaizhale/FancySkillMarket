# 现代风格房屋建造指南

现代风格特点：简洁线条、大窗户、平顶/几何屋顶、黑白灰配色、开放感。

## 材料清单

| 部位 | 推荐材料 | 备选材料 |
|------|----------|----------|
| 外墙 | 白色混凝土、石英块 | 淡灰色混凝土、羊毛 |
| 骨架/装饰 | 深色橡木原木、黑色混凝土 | 深板岩、黑石 |
| 屋顶(平顶) | 深色橡木木板、灰色混凝土 | 石砖、黑石砖 |
| 大窗户 | 玻璃板(浅灰染色) | 玻璃方块、蓝色染色玻璃 |
| 地板 | 云杉木板、石英块 | 白桦木、抛光安山岩 |
| 采光 | 灯笼、海晶灯 | 红石灯(隐藏式) |
| 家具 | 展示框、活板门、楼梯 | 按钮、压力板 |

## 推荐尺寸

现代风适合 **非对称结构**，推荐 L 形或阶梯形：

- 小型：主体 7x7 + 延伸 5x5（L 形）
- 中型：主体 9x7 + 延伸 7x5（L 形或阶梯形）
- 大型：多层错落，主体 11x9 + 二层悬挑

## 核心设计原则

1. **非对称**：不要左右对称，不同高度的体块交错
2. **浅色为主，深色勾勒**：白色墙壁 + 深色边框
3. **大片玻璃**：至少占墙面 30-50%
4. **平顶+悬挑**：屋顶平齐，屋檐挑出半格到 1 格

## 建造步骤（以 L 形中型为例）

### 第一步：确定布局

L 形划分为两个体块：
- 主区域：9x7（客厅+厨房+主卧）
- 副区域：5x5（玄关+楼梯间+次卧）

副区域比主区域矮 1 格，形成高低错落。

### 第二步：地基

```
# 主区域地基
/fill <x> <y> <z> <x+8> <y> <z+6> white_concrete replace
# 副区域地基
/fill <x> <y> <z+6> <x+4> <y> <z+10> white_concrete replace
```

y 为玩家 y 坐标 -1。

### 第三步：骨架（深色边框）

用 **深色橡木原木** 勾勒建筑的轮廓边框：

```
# 四角立柱
/setblock <x> <y+1> <z> dark_oak_log
/setblock <x> <y+2> <z> dark_oak_log
...（直到屋顶高度）

# 水平边框（每层楼板位置）
/fill <x> <y+3> <z> <x+8> <y+3> <z> dark_oak_log replace
```

深色边框包裹整个建筑，白色墙面嵌入其中。

### 第四步：墙壁

```
# 主区域墙壁（高 4 格）
/fill <x+1> <y+1> <z> <x+7> <y+4> <z+6> white_concrete replace

# 副区域墙壁（高 3 格）
/fill <x+1> <y+1> <z+7> <x+3> <y+3> <z+9> white_concrete replace
```

**关键**：不要填满，留出窗户位置。

### 第五步：大窗户（现代风灵魂）

窗户设计：

- **正面**：从地板到天花板的大面积落地窗（宽 3-5 格，高 3 格），用浅灰色染色玻璃板
- **侧面**：横向长条窗（宽 4 格，高 1 格），位置在墙面中部
- **转角窗**：L 形拐角处，两面用玻璃连接

窗户边框用 **深色橡木楼梯** 或 **黑色混凝土** 围一圈。

```
# 正面落地窗示例（宽 4 高 3）
/fill <x+2> <y+1> <z> <x+5> <y+3> <z> light_gray_stained_glass_pane replace
```

### 第六步：入口

- 门：**云杉门** 或 **铁门**
- 门框：**抛光黑石** 或 **深板岩砖** 围一圈
- 门上方挑出 1 格做 **雨棚**（用暗色楼梯倒置）
- 入口平台：3x3 的 **石砖** 或 **石英块**

### 第七步：屋顶（平顶+悬挑）

现代风主要使用平顶，屋檐挑出外墙 1 格：

```
# 主区域平顶（在 y+5 高度）
/fill <x-1> <y+5> <z-1> <x+9> <y+5> <z+7> dark_oak_planks replace
# 用石砖做屋顶围边
/fill <x-1> <y+6> <z-1> <x+9> <y+6> <z+7> stone_brick_slab replace
```

**悬挑设计**：屋顶比墙体外扩 1 格，形成现代风的利落线条感。

### 第八步：二层阳台（可选）

在主区域二楼向外延伸阳台：

```
# 阳台地板（挑出外墙 2 格）
/fill <x+2> <y+4> <z-2> <x+5> <y+4> <z-1> polished_andesite replace

# 阳台围栏（玻璃）
/fill <x+2> <y+5> <z-2> <x+5> <y+5> <z-2> glass_pane replace
```

### 第九步：外观装饰

- **竖向线条**：用深色橡木原木做竖条装饰，从地面通到屋顶，每隔 3 格一条
- **灯光**：屋檐下隐藏 **海晶灯** 或 **灯笼**（用活板门遮挡光源，只露出光线）
- **室外阶梯**：通向门口的石英台阶，宽 3 格

### 第十步：庭院与环境

- 地面铺 **灰色混凝土粉末** 或 **石砖路**
- 种植 **云杉树**（铅笔形，配合现代风格）
- **草坪**修剪整齐，用草径铺出几何形花坛
- 墙角放 **大型观叶植物**（杜鹃花丛、大型蕨）
- 用 **营火** 做户外火坑（上方放烧烤架）

## 现代风成品参考

```
尺寸: L形 9x7 + 5x5，高度 5-6 格
外观: 白色混凝土墙面 + 深色边框 + 大面积玻璃
屋顶: 平顶，屋檐挑出 1 格
氛围: 简洁明亮，几何感，室内外连通
```

## 变体

### 极简白
- 全白外墙（白色混凝土、石英、白桦木）
- 极少的装饰线条
- 超大落地窗，无窗框

### 工业风
- 外墙用 **灰色混凝土** + **铁块**（锈蚀感可用红砖替代）
- 暴露的 **柱子**（深色原木或铁柱）
- 大窗户用 **铁栅栏** 做装饰
- 屋顶可做 **天台花园**

### 错层别墅
- 3 个体块高度不同，错落有致
- 每个体块之间用 **玻璃连廊** 连接
- 楼顶有 **露天平台**
- 利用地形坡度搭建
