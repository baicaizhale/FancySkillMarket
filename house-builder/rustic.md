# 田园风格房屋建造指南

田园风格特点：温暖、自然，使用木材和原石混搭，斜顶带屋檐，有小花园。

## 材料清单

| 部位 | 推荐材料 | 备选材料 |
|------|----------|----------|
| 地基 | 石砖 | 圆石、深板岩 |
| 外墙 | 橡木木板 + 白桦木原木(去皮) | 云杉木板、丛林木 |
| 屋顶 | 橡木楼梯 + 深色橡木楼梯 | 石砖楼梯、红砖 |
| 窗户 | 玻璃板 | 玻璃方块 |
| 门 | 橡木门 | 深色橡木门 |
| 地板 | 橡木木板 | 白桦木板 |
| 装饰 | 栅栏、活板门、花盆、灯笼、藤蔓 | 苔石、草径 |

## 推荐尺寸

- 小型：9 x 7 格（占地）
- 中型：11 x 9 格（占地）
- 大型：13 x 11 格（占地）

## 建造步骤（以 11x9 中型为例）

### 第一步：地基

```
/fill <x1> <y> <z1> <x2> <y> <z2> oak_planks replace
```

- 范围：11x9，厚度 1 格
- y 坐标为玩家 y 坐标 -1

### 第二步：承重柱（四角+关键节点）

在四角和墙体转折处用 **去皮橡木原木** 做柱子，从地板延伸到屋顶：

```
/setblock <x> <y+1> <z> oak_log
/setblock <x> <y+2> <z> oak_log
/setblock <x> <y+3> <z> oak_log
/setblock <x> <y+4> <z> oak_log
```

柱子突出外墙 1 格，形成立体感。

### 第三步：墙壁

外墙主体使用 **橡木木板**，在柱子之间填充。

- **正面（有门）**：柱子之间填木板，留出门洞（宽 2 格，高 3 格）和窗户洞（宽 2 格，在门两侧）
- **侧面**：柱子之间填木板，窗户洞在正中央，宽 3 格高 2 格
- **背面**：柱子之间填木板，可开小窗或封闭

/fill 命令示例：
```
/fill <x1> <y+1> <z1> <x2> <y+4> <z2> oak_planks replace
```

### 第四步：窗户

窗框：用 **深色橡木楼梯** 围着窗户四周放置。
窗户：用 **玻璃板** 填充窗洞。

窗台下方用 **楼梯倒置** 做一个窗台外沿，突出墙面半格。

### 第五步：门

门洞宽 2 高 3。放置两扇橡木门。
门上方用 **去皮橡木原木** 做门梁横跨。
门两侧放 **灯笼** 或 **火把** 做照明。

### 第六步：屋顶（斜顶，带屋檐）

这是田园风的关键。用 **楼梯方块** 从屋檐向屋脊逐级搭建。

以 11x9 房屋为例，屋顶比房屋宽出 2 格（每边挑出 1 格屋檐）：

```
# 屋檐第一层（最底层，用楼梯倒置填充）
/fill <x1-1> <y+5> <z1-1> <x1-1> <y+5> <z2+1> oak_stairs[facing=west,waterlogged=false] replace
/fill <x2+1> <y+5> <z1-1> <x2+1> <y+5> <z2+1> oak_stairs[facing=east,waterlogged=false] replace

# 屋脊线（最顶层）
/fill <x1+3> <y+7> <z1> <x2-3> <y+7> <z2> dark_oak_stairs replace
```

每层楼梯向屋脊缩进 1 格，一直堆叠到屋脊。屋脊用深色橡木楼梯做装饰线。

简易实现：用 `/fill` 的 outline 模式配合楼梯方块填充：
```
/fill <x1-1> <y+5> <z1-1> <x2+1> <y+7> <z2+1> oak_planks hollow
```
然后在最外层覆盖楼梯方块做斜面纹理。

### 第七步：窗户细节

- 窗户外侧上方用 **活板门** 打开状态做遮阳蓬
- 窗台摆放 **花盆**（玫瑰、向日葵、百合）
- 窗户内侧可加 **窗帘**（用深色地毯挂在墙顶）

### 第八步：入口装饰

- 门前 3x3 区域铺 **石砖路**（或草径）
- 门两侧放 **栅栏** 围成小门廊
- 门廊上方用 **活板门** 做棚顶
- 门口放 **灯笼照明**

### 第九步：花园与环境

- 房屋周围留 1-2 格宽的花坛
- 花坛用 **草径** 或 **泥土** 围边，内部种花
- 种 2-3 棵 **橡树** 或 **白桦**
- 用 **栅栏** 围出小院子
- 院子角落放 **堆肥桶** 和 **蜂箱**

### 第十步：室内装饰

- 地毯：用浅色地毯铺在床前
- 壁炉：墙角用石砖砌壁炉，内部放 **营火**（上方放灵魂火把做抽风效果）
- 照明：天花板挂 **灯笼**，墙上放 **火把**
- 书架：靠墙放书架，中间穿插 **画**
- 厨房区域：**熔炉**+**烟熏炉**+**工作台** 组合

## 田园风成品参考

```
尺寸: 11 x 9 x 7 (长x宽x高)
外观: 浅色木板墙 + 深色原木骨架 + 深色斜顶 + 白色窗户框
环境: 花园环绕，栅栏院子，门前石板路
氛围: 暖色调照明，花草装饰，烟囱炊烟
```

## 变体

### 河畔小屋
- 建在河边或湖边
- 增加 **钓鱼码头**（用木板向水面延伸）
- 阳台用 **栅栏** 围起
- 增加 **箱子船** 停靠

### 森林木屋
- 建在树丛间
- 外墙多用 **云杉木**
- 屋顶用 **苔石** 或 **苔藓块**
- 周围保留树木不砍伐
