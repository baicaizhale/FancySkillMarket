# 中世纪风格房屋建造指南

中世纪风格特点：厚重石材、高耸尖顶、城墙式结构、深色木构架、染色玻璃。

## 材料清单

| 部位 | 推荐材料 | 备选材料 |
|------|----------|----------|
| 地基 | 石砖 | 深板岩砖、磨制安山岩 |
| 外墙底层 | 圆石/石砖 | 苔石、裂纹石砖 |
| 外墙上层 | 深色橡木木板 | 云杉木板 |
| 木构架 | 深色橡木原木 | 云杉原木、橡木原木 |
| 屋顶 | 深色橡木楼梯 | 石砖楼梯、紫红色陶瓦 |
| 染色玻璃 | 紫色/红色/蓝色染色玻璃板 | 对应玻璃方块 |
| 装饰 | 石砖栅栏、铁栏杆、按钮 | 活板门、原木、苔石 |

## 推荐尺寸

中世纪建筑强调 **垂直感**，高度要大于宽度：

- 小屋：7 x 9（宽 x 长），高度 7
- 主楼：9 x 11（宽 x 长），高度 9
- 塔楼：7 x 7 或 5 x 5，高度 12+

## 核心设计元素

1. **木架结构（Fachwerk）**：深色原木在浅色墙面外形成纵横骨架
2. **尖顶/高斜顶**：屋顶坡度陡峭，挑出屋檐
3. **城墙垛**：屋顶边缘用石砖栅栏或楼梯做城垛
4. **拱形**：门洞和窗洞用楼梯做拱形顶
5. **塔楼**：圆形或方形塔楼连接主体

## 建造步骤（以 9x11 主楼为例）

### 第一步：地基

```
/fill <x> <y> <z> <x+8> <y> <z+10> stone_bricks replace
```

y 为玩家 y 坐标 -1，地基厚度 1 格。

地基要比外墙宽出 1 格，形成基石外沿：
```
/fill <x-1> <y> <z-1> <x+9> <y> <z+11> stone_bricks outline
```

### 第二步：骨架（木构架）

中世纪风格核心——**深色原木骨架外露**。

```
# 四角立柱（从地基到屋檐）
/fill <x> <y+1> <y+6> <z> dark_oak_log replace

# 水平横梁（每隔 2 格高度一条）
/fill <x+1> <y+3> <z> <x+7> <y+3> <z> dark_oak_log replace
/fill <x+1> <y+3> <z+10> <x+7> <y+3> <z+10> dark_oak_log replace

# 斜向支撑（用楼梯模拟）
/setblock <x+1> <y+4> <w> dark_oak_stairs[facing=east] replace
```

### 第三步：墙壁填充

在原木骨架之间填充 **浅色墙面**：

```
# 墙面填充（注意留出门窗洞）
/fill <x+1> <y+1> <z+1> <x+7> <y+2> <z+9> white_wool replace
```

底层用 **石砖**（高 2 格），上层用 **白色羊毛** 或 **淡灰色羊毛**（模拟抹灰墙面）：

```
# 石砌底层
/fill <x+1> <y+1> <z+1> <x+7> <y+2> <z+9> stone_bricks replace

# 抹灰上层
/fill <x+1> <y+4> <z+1> <x+7> <y+6> <z+9> white_wool replace
```

### 第四步：门窗洞

门洞：宽 2 格，高 3 格，上方用楼梯做成 **拱形**：
```
# 门洞两侧
/setblock <x+3> <y+1> <z> air replace
/setblock <x+4> <y+1> <z> air replace
/setblock <x+3> <y+2> <z> air replace
/setblock <x+4> <y+2> <z> air replace
/setblock <x+3> <y+3> <z> air replace
/setblock <x+4> <y+3> <z> air replace
# 拱顶（用楼梯）
/setblock <x+2> <y+4> <z> stone_brick_stairs[facing=east] replace
/setblock <x+5> <y+4> <z> stone_brick_stairs[facing=west] replace
```

窗户：窄而高（宽 1 高 3），顶部同样用拱形。
用 **染色玻璃板**（紫色或红色）。

### 第五步：门

- 中世纪风格大门：两扇 **深色橡木门** 并排
- 门上方的拱形空间用 **石砖栅栏** 填充
- 门环：两侧各放一个 **铁栏杆**（挂在门上）

### 第六步：窗户细节

- 窗户外框用 **石砖楼梯** 围一圈
- 窗台用 **深色橡木楼梯倒置** 突出墙面
- 染色玻璃板（紫色/红色/蓝色）
- 窗外可加 **铁栏杆** 防盗（中世纪特色）

### 第七步：屋顶（高斜顶带城垛）

这是中世纪风格最有辨识度的部分：

```
# 山墙端（正面/背面三角形墙面）
# 用楼梯搭建三角形
# 最底层：宽 9 格
/fill <x> <y+7> <z> <x+8> <y+7> <z> dark_oak_stairs replace
# 依次收窄...

# 斜面屋顶（用 outline 简化）
/fill <x-1> <y+7> <z-1> <x+9> <y+10> <z+11> dark_oak_planks hollow
# 再用楼梯覆盖表面做斜面纹理
```

**城垛**：屋顶边缘用石砖栅栏或楼梯做城墙垛口：
```
# 屋檐边缘树城垛
/fill <x-1> <y+7> <z-1> <x+9> <y+7> <z-1> stone_brick_wall replace
# 每隔一格留空
/setblock <x+1> <y+7> <z-1> air replace
/setblock <x+3> <y+7> <z-1> air replace
```

### 第八步：塔楼（可选）

在主楼四角之一加方形塔楼，高 12+：

```
# 塔楼地基 5x5
/fill <x+9> <y> <z-4> <x+13> <y> <z> stone_bricks replace

# 塔楼墙壁（4 格高一层，共 3 层）
/fill <x+9> <y+1> <z-4> <x+13> <y+12> <z> stone_bricks hollow

# 塔楼尖顶（用楼梯逐级收窄）
# 四角用楼梯向中心收拢...
```

### 第九步：外部装饰

- **旗帜**：塔楼顶插 **白色或红色旗帜**（用羊毛右键）
- **火炬**：门两侧和城垛上放 **火把**（中世纪照明）
- **吊闸门**：入口上方用 **铁栏杆** 做吊闸效果
- **护城河**：建筑外围挖 2 格宽的沟渠，注水

### 第十步：庭院

- 铺装：**石砖路** 宽 3 格
- 水井：3x3 石砖围边，中间挖 2 格深注水
- 灯柱：**深色橡木栅栏** + 顶部 **灯笼**
- **马厩**：小棚屋，放干草捆
- **锻造区**：**高炉** + **铁砧** + 原材料箱子

## 中世纪风成品参考

```
尺寸: 9 x 11 x 10（主体），加塔楼更高
外观: 石砌底层 + 抹灰木架墙 + 深色高斜顶
防御: 城垛、窄窗、厚重石材
氛围: 沉稳威严，灯火通明，历史感
```

## 变体

### 城堡式
- 矩形主体，四角各一座塔楼
- 塔楼之间用 **城墙** 连接（石砖栅栏）
- 入口设 **吊桥**（用活板门模拟）
- 主体高度至少 3 层

### 酒馆
- 一层做大空间（客厅+吧台）
- 用 **云杉木板** 做地板
- 大量 **灯笼** 照明
- 外部门口挂 **招牌**（用展示框放物品）

### 修道院/教堂
- 建筑呈十字形布局
- 中央大厅高耸（高 10+）
- 拱形 **穹顶** 屋顶
- 大面积 **紫色染色玻璃**
- 内部长排 **椅子**（用楼梯和栅栏组合）
