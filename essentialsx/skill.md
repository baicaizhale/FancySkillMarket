# EssentialsX 完整命令指南

## 插件检查

在使用以下命令前，请先检查服务器是否已安装 EssentialsX 插件。

检查方法：尝试执行 `/essentials` 或 `/ess version` 命令，如果返回版本信息则说明插件已安装。

如果插件未安装，请告知玩家使用 Minecraft 原版命令（如 `/gamemode`、`/tp`、`/give`）来替代。

## 模块说明

EssentialsX 包含多个模块，不同模块提供不同功能：

| 模块 | 功能 |
|------|------|
| EssentialsX（核心） | 传送、经济、物品、玩家管理等基础功能 |
| EssentialsX Chat | 聊天格式、前缀后缀、彩色聊天 |
| EssentialsX Spawn | 出生点控制、`/spawn` 命令 |
| EssentialsX Protect | 基础方块保护（防爆、防岩浆等） |
| EssentialsX AntiBuild | 建筑权限控制 |
| EssentialsX Discord | Discord 机器人集成 |
| EssentialsX GeoIP | 玩家地理位置信息 |

## 核心命令

| 命令 | 说明 |
|------|------|
| `/essentials` 或 `/ess` | 查看插件版本与基本信息 |
| `/ess reload` | 重新加载 EssentialsX 配置文件 |
| `/ess reload <模块>` | 重载指定模块（如 `chat`、`spawn`） |
| `/gc` | 查看服务器资源占用（内存、TPS、实体数、区块数） |
| `/help [页码\|关键词]` | 查看帮助信息 |
| `/help <类别>` | 查看指定类别的帮助（如 `teleport`、`economy`） |

## 牌商店 (Sign Shop)

玩家可以在地上放置牌子来开设商店：

- **出售**：第一行 `[Sell]`，第二行数量，第三行单价
- **购买**：第一行 `[Buy]`，第二行数量，第三行单价
- **交易**：第一行 `[Trade]`，第二行给出手中的物品数量，第三行得到物品数量
- 右键牌子进行交易
- 左键可查看商店信息
- 需要 `essentials.signs.use.*` 权限

## 注意事项

- EssentialsX 和 CMI 功能高度重叠，两插件**不应共存**，选其一安装
- Chat 模块提供聊天格式功能，需要配合 LuckPerms 等权限插件的 meta（prefix/suffix）
- Spawn 模块需要单独安装才能使用 `/spawn` 和 `/setspawn`
- Protect 模块提供基础保护（防爆、防岩浆蔓延），但不如 WorldGuard/Residence 专业
- AntiBuild 可以限制特定权限组的建筑行为
- 传送请求有默认超时时间（`config.yml` 中配置，默认 60 秒）
- `/back` 可以回到死亡位置，但死后需先重生再执行
- `/heal` 和 `/feed` 默认只对自己生效，需额外权限才能用于其他玩家
- 经济功能需要先安装 Vault 和经济后端插件
- 牌商店的物品名称支持中文，但需要打中文在牌子上
