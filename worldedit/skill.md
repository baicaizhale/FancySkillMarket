# WorldEdit 世界编辑完整指南

## 插件检查

在使用以下命令前，请先检查服务器是否已安装 WorldEdit 插件。

检查方法：尝试执行 `//version` 命令，如果返回版本信息则说明插件已安装。

如果插件未安装，请告知玩家 WE 命令不可用，改用原版 `/fill`、`/setblock`、`/clone` 命令替代。
**注意**：FAWE (FastAsyncWorldEdit) 是 WorldEdit 的高性能替代品，命令基本兼容。

## 选区操作

### 选择工具

默认使用木斧（Wooden Axe）：
- **左键**点击方块 = 设置第一个点（pos1）
- **右键**点击方块 = 设置第二个点（pos2）

| 命令 | 说明 |
|------|------|
| `//wand` | 获取选区工具（木斧） |
| `//pos1` | 将脚下方块设为第一点 |
| `//pos2` | 将脚下方块设为第二点 |
| `//hpos1` | 将指向的方块设为第一点 |
| `//hpos2` | 将指向的方块设为第二点 |
| `//size` | 查看当前选区尺寸（长宽高和总方块数） |
| `//count <方块>` | 统计选区内指定方块的数量 |
| `//distr` | 统计选区内所有方块类型的分布 |
| `//expand <数量> [方向]` | 扩展选区（方向：up/down/north/south/east/west） |
| `//expand vert` | 将选区垂直扩展到天花板和地板 |
| `//contract <数量> [方向]` | 缩小选区 |
| `//shift <数量> [方向]` | 移动选区位置（不改变方块） |
| `//outset <数量>` | 向所有方向扩展选区 |
| `//inset <数量>` | 向所有方向缩小选区 |
| `//sel` | 清除选区（别名 `//desel`） |

## 基础编辑

### 方块操作

| 命令 | 说明 |
|------|------|
| `//set <方块>` | 将选区全部设置为指定方块 |
| `//replace <旧方块> <新方块>` | 替换选区内指定方块 |
| `//replace <旧方块1>,<旧方块2> <新方块>` | 批量替换多种方块 |
| `//walls <方块>` | 沿选区边界生成墙壁 |
| `//outline <方块>` | 沿选区边界生成轮廓（6个面） |
| `//faces <方块>` | 仅生成选区的四个侧面（不含顶底） |
| `//drain <半径>` | 抽干半径范围内的液体（水/岩浆） |
| `//fill <方块> <半径> [深度]` | 填充选区内空洞 |
| `//fillr <方块> <半径>` | 递归填充（将空洞填满不溢出） |
| `//regen` | 重新生成选区地形（恢复为原始生成状态） |
| `//naturalize` | 用草方块替换表层，石头×3替换下层，矿化选区 |

### 撤销与重做

| 命令 | 说明 |
|------|------|
| `//undo [次数]` | 撤销上一步操作 |
| `//redo [次数]` | 重做撤销的操作 |
| `/clearhistory` | 清除操作历史 |

### 剪贴板

| 命令 | 说明 |
|------|------|
| `//copy` | 复制选区（以位置为参考） |
| `//cut` | 剪切选区（复制后填充空气） |
| `//paste` | 粘贴剪贴板内容 |
| `//paste -a` | 粘贴时不包含空气方块 |
| `//rotate <角度>` | 旋转剪贴板内容（90/180/270） |
| `//flip [方向]` | 翻转剪贴板内容（up/down/north/south/east/west） |
| `//move <距离> [方向]` | 移动选区方块 |
| `//stack <次数> [方向]` | 沿指定方向堆叠选区 |
| `/clearclipboard` | 清除剪贴板 |

## 形状生成

### 基础形状

| 命令 | 说明 |
|------|------|
| `//sphere <方块> <半径>` | 生成实心球体 |
| `//sphere <方块> <半径> false` | 生成空心球体（仅外壳） |
| `//cyl <方块> <半径> <高度>` | 生成实心圆柱体 |
| `//hcyl <方块> <半径> <高度>` | 生成空心圆柱体 |
| `//dome <方块> <半径>` | 生成穹顶（半球） |
| `//pyramid <方块> <高度>` | 生成实心金字塔 |
| `//hpyramid <方块> <高度>` | 生成空心金字塔 |

### v7.3+ 新增命令 (2024)

| 命令 | 说明 |
|------|------|
| `//cone <方块> <半径> <高度>` | 生成圆锥体 |
| `//update [副作用类型]` | 对选区应用方块副作用（如更新方块状态） |
| `//placement <模式>` | 选择放置模式：`min`（最小Y）、`max`（最大Y）、`world`（世界）、`here`（当前位置） |
| `//trim [遮罩]` | 将选区修剪到最小空间 |
| `//feature [特性名]` | 生成地形特性 |
| `//structure [结构名]` | 生成建筑结构 |
| `/brush splatter <图案> [半径] [衰减]` | 溅射画笔（边缘渐淡） |
| `/brush morph <形状> [半径] [迭代]` | 形态画笔（膨胀/腐蚀） |
| `//schem share` | 分享蓝图文件 |

### 高级形状

| 命令 | 说明 |
|------|------|
| `//hollow [厚度]` | 将选区内方块掏空 |
| `//smooth [迭代]` | 平滑选区内地形 |
| `//overlay <方块>` | 在选区表面覆盖一层方块 |
| `//forest <树种> [密度]` | 在选区表面生成森林（自动种树） |
| `//flora [密度]` | 在选区表面生成植被（花、草等） |
| `//line <方块> [厚度]` | 在两点之间生成线段 |
| `//curve <方块> [厚度]` | 在多点之间生成贝塞尔曲线 |
| `//deform <表达式>` | 根据数学表达式变形选区（如 `y = y + sin(x) * cos(z)`） |
| `//generate <表达式>` | 根据数学表达式生成方块（如 `x^2 + y^2 + z^2 < 10^2`） |

### 表达式变量

`//generate` 和 `//deform` 支持变量：`x`、`y`、`z`（坐标），`type`（当前方块ID），`data`（方块数据值）。

示例：
```
//generate stone (x^2 + y^2 + z^2 < 15^2) && (x^2 + y^2 + z^2 > 12^2)
```

## 画笔系统 (Brushes)

画笔是绑定在手持物品上的工具，右键/左键方块时触发。

### 画笔命令

| 命令 | 说明 |
|------|------|
| `/brush sphere <方块> <半径>` | 球形画笔（右键生成球体） |
| `/brush cyl <方块> <半径> <高度>` | 圆柱画笔 |
| `/brush smooth [半径] [迭代次数]` | 平滑画笔 |
| `/brush deform <表达式>` | 变形画笔 |
| `/brush clipboard` | 粘贴画笔（配合 //copy 使用） |
| `/brush butcher [半径]` | 清除画笔（清除范围内实体） |
| `/brush height <方块> <半径>` | 高度画笔（提高地形） |
| `/brush flatten <方块> <半径>` | 平整画笔（平整地形） |
| `/brush gravity <方块> <半径>` | 重力画笔（让方块下落） |
| `/brush erode [半径]` | 侵蚀画笔（模拟风蚀效果） |
| `/brush ex <半径> <方块1>,<方块2>` | 林火画笔（熄灭火焰并替换） |
| `/none` | 清除手中物品绑定的画笔 |
| `/mask` | 为画笔设置遮罩（仅影响特定方块） |

### 画笔距离

- 画笔可以设置作用距离：`/brush sphere stone 5 10`（半径 5，距离 10 格）
- 默认距离为玩家可达范围

## 遮罩与过滤器

遮罩控制哪些方块受影响，可叠加多种条件。

| 命令 | 说明 |
|------|------|
| `//mask <方块>` | 仅影响指定方块 |
| `//mask !<方块>` | 不影响指定方块（反向遮罩） |
| `//mask ><方块>` | 仅影响该方块类型之上的方块 |
| `//mask <<方块>` | 仅影响该方块类型之下的方块 |
| `//mask /<角度>` | 仅影响指定坡度的面 |
| `//gmask <方块>` | 设置全局遮罩（对所有操作生效） |
| `/mask` | 清除遮罩 |
| `/gmask` | 清除全局遮罩 |

## 变换 (Transform)

配合剪贴板粘贴使用，可对粘贴内容进行变换：

| 命令 | 说明 |
|------|------|
| `//gtransform` | 交互式全局变换（GUI 菜单） |
| `//transform <表达式>` | 选取后变换方块 |

## 蓝图 (Schematic)

蓝图是保存到文件的建筑模板，可跨服务器使用。

| 命令 | 说明 |
|------|------|
| `//schematic save <文件名>` | 保存选区为蓝图文件 |
| `//schematic load <文件名>` | 加载蓝图 |
| `//schematic delete <文件名>` | 删除蓝图文件 |
| `//schematic list` | 列出所有蓝图（可筛选） |
| `//schematic formats` | 查看支持的蓝图格式 |
| `/schem load <文件名>` | `/schematic` 的简写 |

蓝图文件存储在 `plugins/WorldEdit/schematics/` 下，支持 `.schem`、`.schematic` 格式。

## 模式语法 (Patterns)

WE 支持丰富的方块模式语法，在 `//set`、`//replace` 等命令中使用：

| 模式 | 示例 | 说明 |
|------|------|------|
| 单一方块 | `//set stone` | 全部设为石头 |
| 随机混合 | `//set stone,dirt,grass_block` | 随机选取三种方块之一 |
| 权重混合 | `//set 50%stone,30%dirt,20%grass_block` | 按权重比例混合 |
| 复合模式 | `//set #clipboard,#copy` | 粘贴剪贴板 |
| 模糊匹配 | `//replace ##sand #dirt` | 匹配所有带"sand"的方块 |
| 空气排除 | `//set !air` | 仅设置非空气方块 |

## 速建示例

### 生成圆形平台
```
//sel clear → /center → //sphere stone 20
//hcyl stone 20 1
```

### 复制一栋建筑
```
//wand → 选区 → //copy → 移动到目标位置 → //paste
```

### 地形平滑
```
//wand → 选区 → //smooth 3
```

### 批量替换并保留部分
```
//mask !stone_bricks → //replace cobblestone stone
```
（替换圆石为石砖，但保留已存在的石砖）

## 注意事项

- 大型操作前建议先用 `//limit` 查看方块操作上限，避免误操作
- `//undo` 可以撤销几乎所有操作，但跨服务器重启后历史会丢失
- 使用 `//fast` 可在低配服务器上加速大型操作（牺牲视觉效果）
- FAWE (FastAsyncWorldEdit) 是 WorldEdit 的第三方高性能分支，命令兼容，大服推荐使用
- 选区操作在大型区域（10万+方块）时应谨慎，可能导致服务器卡顿或回滚
- `/clearhistory` 不可撤销，清除后无法 `//undo`
- 画笔和工具绑定在手头物品上，切换物品后绑定丢失
- 蓝图文件区分大小写，文件名不要包含空格
